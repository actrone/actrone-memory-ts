    Node vocabulary

    Icon and label carry a span's kind, never colour, so eleven kinds need no categorical palette and chroma stays free for state. A span with an ok outcome shows no tag at all: the map is quiet until something needs a look.

    • agent

      One agent run, root or sub-agent

    • chat

      One model call: model id, tokens, cost

    • tool

      One execution, paired to its request by tool_call_id

    • context

      What entered the prompt, and what was dropped and why

    • memory

      L1 and L2 hits with ids and scores

    • policy

      DPE verdict, rule and policy version

    • approval

      Who approved, and how long the write was held

    • action

      GAL write with its Ed25519 receipt

    • handoff

      MACP spawn of a sub-agent run, drawn as a group

    • a2a

      Cross-org call: only what the peer attests

    • mediaguard

      Redaction counts, never the redacted value

    Skill recommendations rejected on brand grounds

    • ui-ux-pro-max design system: proposed Fira Code and Fira Sans, a slate palette with a green accent, and oversized display type. Rejected: Geist only, monochrome canvas, dense app scale.
    • ui-ux-pro-max network chart guidance: categorical node colours and an amber highlight path. Rejected: kind is icon plus label, and the active path is drawn in ink, because chroma is reserved for state.
    • ui-ux-pro-max icon default: Phosphor. Rejected: lucide at stroke width 1.5.
    • web-design-guidelines copy rule: Title Case for headings and buttons. Rejected: sentence case everywhere.
    • design prompt v1.0: a pulsing 6px running dot. Superseded: status dots were retired from the brand; running is a text tag plus a held ink border.

| Phase | Theme | Depends on | Infra needed beyond current |
|---|---|---|---|

## 4. Cross-cutting engineering standards (applied to EVERY PR)

Non-negotiable. A change is **not done** until all apply ([CLAUDE.md §11](../CLAUDE.md)):

**Security & data**
- No hardcoded secrets; all secrets via vault/env. BYOK/channel/provider keys **sealed, never logged, never returned** (masked hints only).
- Input validation (allowlist) at every boundary; max-length caps; oversized-payload rejection.
- Authz in the **service layer** (scoped RBAC), not just the gateway/UI. Entitlement + scope checked before render *and* server-side.
- All model/web/channel content through **MAL** before the LLM; all model output **XSS-sanitised** before render.

**Reliability**
- `context.Context` + timeout on every I/O; retries = exp backoff + jitter, max 3; circuit breakers on outbound.
- Idempotency keys on every write endpoint (reuse same key on retry — CLAUDE.md §6.2).
- Graceful shutdown; structured JSON logs with `service/request_id/trace_id/event`; OTel traceparent propagated.
- Migrations backwards-compatible + reversible (goose); never `UPDATE/DELETE` audit/financial rows.

**Code & UI quality**
- Go: errors wrapped `%w`; no `init()` side effects; `errgroup` + bounded concurrency. Python: `mypy --strict`, all I/O async. TS: `strict`, no `any` without `// UNSAFE:`, ESM, `zod` validation, native `fetch`/`ky` (no axios), `date-fns`.
- UI: design tokens only (no hardcoded colour/spacing); **loading + empty + error states designed** for every async surface; full a11y (ARIA, focus, keyboard, ≥4.5:1, reduced-motion); responsive at 375/768/1280/1920.
- Public APIs documented; functions < 50 lines / complexity ≤ 10; self-documenting names.
- Deps pinned + justified; `govulncheck`/`pip-audit`/`npm audit` clean (no HIGH/CRITICAL).

**Testing (CLAUDE.md §7)**
- Unit ≥ 80% business logic, table-driven, error paths tested with equal rigour; deterministic (no `time.Sleep`).
- Integration via testcontainers for every repository/adapter; contract tests on every API; E2E (Playwright) for critical journeys + `axe` a11y zero-violations on revamped routes.

**Git discipline:** Conventional Commits; atomic, buildable commits; meaningful PR titles. *(Note: workspace is currently not a git repo — initialise before the first PR if version control is desired.)*
